## Commands

Package manager is **Bun**. Do not use npm or yarn.

```bash
bun install          # Install dependencies
bun run dev          # Start Vite dev server
bun run build        # Type-check (tsc -b) then Vite production build
bun run lint         # ESLint
bun run preview      # Preview production build locally
```

Route tree is auto-generated by TanStack Router plugin during dev/build. If adding routes manually or outside the dev server, regenerate with:

```bash
npx @tanstack/router-cli generate
```

## Environment

Requires a `.env` file with:

```
VITE_BACKEND_URL=http://localhost:8080
```

The app will throw at startup if `VITE_BACKEND_URL` is not set.

## Architecture

**React 19 + TypeScript + Vite** SPA with React Compiler enabled for automatic memoization.

### Routing

File-based routing via **TanStack Router** in `src/routes/`. The route tree (`src/routeTree.gen.ts`) is auto-generated — never edit it manually.

- `__root.tsx` — Root layout, wraps providers (QueryClient, Auth, Devtools)
- `_authenticated.tsx` — Layout guard for auth-protected routes; redirects to `/auth` if unauthenticated
- `_authenticated/` — All protected page routes live here
- `auth/index.tsx` — Login page (OAuth + OTP)

### Domain Layer (`src/domains/`)

DDD-inspired feature modules. Each domain follows the pattern:

- `types.ts` — DTOs, request/response interfaces
- `service.ts` — API endpoint schema definitions using `endpoint()` helper
- `hooks.ts` — React hooks (React Query mutations/queries for the domain)

Domains: `auth`, `projects`, `users`, `invitations`

The unified API client is initialized in `src/domains/index.ts` and exports `api` — use `api.<domain>.<method>()` for all backend calls.

### Custom API Client (`src/lib/api-client/`)

Schema-driven, type-safe HTTP client with:

- `endpoint()` + `t<Type>()` helpers for defining typed endpoints
- Token auth middleware with automatic refresh (`tokenAuth`)
- Request deduplication, retry with exponential backoff, concurrency control
- React Query integration with tag-based cache invalidation (`queryKeys`, `$tagRegistry`)
- Error types: `HttpError`, `NetworkError`, `TimeoutError`, `ParseError`

### UI & Styling

- **Tailwind CSS v4** with CSS custom properties for theming (brand colors defined in `src/index.css`)
- **shadcn/ui** components in `src/components/ui/` — 58+ components, New York style variant
- **Radix UI** primitives underpin all accessible components
- Layout components in `src/components/layout/` (sidebar, header, breadcrumbs)
- `cn()` utility from `src/lib/utils.ts` for class merging (clsx + tailwind-merge)

### State & Data Fetching

- **TanStack React Query** for server state (configured in `src/lib/query-client.ts`, 60s stale time, 5min GC)
- Auth state via React context (`src/lib/auth.tsx`, `useAuth()` hook)
- Forms use **React Hook Form** + **Zod** for validation

### Path Alias

`@` maps to `./src` (configured in both `vite.config.ts` and `tsconfig.json`). Always use `@/` imports.

## Adding a New Domain

1. Create `src/domains/<name>/types.ts`, `service.ts`, `hooks.ts`
2. Define endpoints in `service.ts` using `endpoint()` and `t<Type>()`
3. Add the schema to the unified client in `src/domains/index.ts`
4. Write React Query hooks in `hooks.ts` using `api.<domain>.<method>()`

## Adding a New Route

Create a file under `src/routes/`. Protected routes go in `src/routes/_authenticated/`. The TanStack Router plugin auto-generates the route tree during dev.
